# BEN V42 — Visual Design System

V42 moves BEN from prototype UI toward a cohesive product surface.

- Cyan/teal is the primary BEN accent.
- Dark surfaces use layered navy panels and restrained glow.
- Main shell uses translucent glass navigation/header surfaces.
- Page identity is carried by motion, spacing, typography and the BEN mark rather than generic Material cards.
- V35 map behavior is preserved; no map implementation was rewritten.
- BEN Center / V39 Hub remain removed from normal user navigation.

This release is a visual foundation pass across the five primary surfaces: Akış, Dünya, Keşfet, Mesajlar and Profil.
