# BENApp V130 — Memory Tree Design

- Profile Ağacım redesigned around a cinematic, dark memory-tree canvas.
- Permanent memories only (`story` memories are excluded from the tree).
- Latest permanent memory becomes the glowing central/root memory.
- Memories are grouped by day and distributed in five-point/pentagonal buds.
- Branches grow diagonally upward from the trunk and connect each pentagonal cluster.
- Photo memories use their real local photo as circular branch nodes when available.
- Tapping a memory still opens the existing MemoryDetailScreen.
- InteractiveViewer provides pan + zoom; controls provide zoom in/out/reset.
- New nodes animate into the tree with a short growth-style scale animation.
- Existing BEN / Harita / + / Mesajlar / Profil navigation remains unchanged.
